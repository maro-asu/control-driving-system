本リポジトリは，車間距離制御の制御則を用いて数値シミュレーションを行い，先行車の速度変化に対して
後続車がどのように追従するかを確認し，また，制御ゲインの値を変更し，車間距離や速度，加速度の時間変化を
比較することで，ゲインが追従性能に与える影響について考察するためのコードである．

本研究では，先行車1台と後続車1台からなる簡単な車両モデルを対象とする．実際の車両に存在する複雑な運動
特性や通信遅延などは考慮せず，車両の位置，速度，加速度を用いた基本的なモデルによって制御の挙動を調べた．

シミュレーション時間を30s，計算刻み幅を∆t=0.01s とする．
先行車の初期位置を xL(0)=30m，後続車の初期位置をxF(0)=0m とし，
両車両の初期速度を
vL(0) = vF(0) = 15m/s
と設定する．このとき，初期車間距離は30mである．
目標車間距離はdref = 30mとする．

シミュレーション結果から，以下の3項目について評価した．
1. 車間距離の変化
実際の車間距離d(t) と目標車間距離 dref を比較し，先行車の減速によって車間距離がどのように変化するか
を確認する．また，車間距離が目標値からどの程度変化し，その後どのように目標値に近づくかを調べる．
2. 車両速度の変化
先行車と後続車の速度を比較し，先行車の減速に対して後続車がどのように速度を変化させるかを確認する．
両車両の速度差の変化から，追従動作の特徴を調べる．
3. 後続車の加速度の変化
後続車の加速度を確認し，制御入力がどのように変化するかを調べる．加速度の変化が大きい場合には，車両
の動きが急激になる可能性があるため，車間距離や速度の変化と合わせて評価する．

さらに，制御ゲインが追従性能に与える影響を調べるため，Kv =0.8を固定し，Kd を変更したシミュレーションを行った．
